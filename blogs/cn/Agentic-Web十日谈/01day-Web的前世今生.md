# Agentic Web 十日谈·第一日：从万维网到超级平台——Web 封闭化的历史必然性

> **核心问题**：一个为"连接"而生的网络，为什么会不可避免地走向平台化与封闭？

1989年，一位在欧洲核子研究中心(CERN)工作的英国科学家 Tim Berners-Lee 提交了一份看似平淡的提案，标题是"信息管理：一个提案"。他的上司在这份提案上写下了"模糊但令人兴奋"的评语。

这个"模糊"的提案，最终改变了整个世界。它就是我们今天所说的万维网(World Wide Web)的雏形。

三十多年后的今天，当我们回望这段历史时，会发现一个令人困惑的悖论：**一个为"连接"而生的开放网络，为什么最终走向了平台垄断和数据孤岛？**

这不是一个关于道德选择的故事，而是一个关于生产力演进的故事。理解这段历史，是理解为什么 AI 时代需要一个全新互联网的前提。

## 本文核心要点

- **为什么叫 Web**：Tim Berners-Lee 的初心是"连接即权力"，让任何人都能自由连接信息、连接他人
- **HTTP 协议为什么成功**：简单、开放、无需许可、基于现有基础设施——这四大原则成就了互联网革命
- **Web 2.0 的转折**：从开放走向封闭，不是背叛，而是为人类注意力和操作能力优化的必然结果
- **语义网为什么失败**：人工标注成本过高、缺乏商业驱动力、技术栈过于复杂——三座大山压垮了一个美好愿景
- **Web3 的局限**：把"信任问题"简化为"上链问题"，忽视了用户体验与生产力现实
- **一个关键判断**：封闭不是阴谋，而是旧生产力条件下的最优解——规模效应驱动了平台垄断的形成

## 一、万维网的初心：连接即权力

很多人第一次听到"World Wide Web"这个名字时，都会好奇：为什么叫"网"？

Tim Berners-Lee 的答案很简单：**因为信息不应该是树状的，而应该是网状的**。

在 Web 之前，信息系统大多是层级结构——像图书馆的分类法，或者文件系统的目录树。但现实世界的信息，从来不是这样组织的。一篇论文可能同时涉及多个学科，一个人可能同时扮演多个角色，信息之间的关系，更像是一张错综复杂的网。

**超链接**，就是 Tim Berners-Lee 交出的答案。通过 URL 和 HTML，任何人都可以创建一个网页，并将它链接到互联网上的任何其他网页。信息不再被困在孤岛中，而是通过链接自由流动。

这背后的理念，就是**"连接即权力"**(Connection is Power)。

### 连接即权力的原始含义

在 Web 诞生的年代，"连接即权力"有三层含义：

1. **谁能被连接，谁就能被看见**：你的网页只要挂在互联网上，全世界任何人都可以访问
2. **谁能创建连接，谁就能组织知识**：通过超链接，任何人都可以构建自己的知识网络
3. **谁能自由连接，谁就拥有自主权**：不需要任何中介，不需要任何许可

这个理念在今天听起来可能有些陈旧，但在三十多年前，它是革命性的。

更重要的是，Web 最早是一种**基础设施，而非平台**。它不属于任何公司，不由任何机构控制，任何人都可以自由使用。

**开放，是起点，不是口号。**

## 二、Web 1.0：HTTP 为什么能成功？

如果说超链接是 Web 的灵魂，那么 HTTP 协议就是 Web 的骨架。

HTTP 为什么能成功？为什么它能在三十多年后的今天，依然是互联网的基石？

答案可以归纳为四个关键条件：

### 1. 简单(Simplicity)

HTTP 的核心理念极其简单：客户端发送请求，服务器返回响应。就这么简单。

最早的 HTTP/0.9 协议，整个规范只有一页纸。请求只有一行：`GET /index.html`，响应就是直接返回 HTML 文档。没有请求头，没有状态码，没有复杂的握手过程。

这种极简主义，让任何人都能快速理解和实现 HTTP。你不需要博士学位，不需要昂贵的设备，甚至不需要专门的培训——只要你懂一点编程，就能搭建一个 Web 服务器。

**简单，降低了门槛；门槛低，就有更多人参与；参与的人多了，生态就起来了。**

### 2. 开放(Openness)

Tim Berners-Lee 做了一个至关重要的决定：他没有为 Web 技术申请专利，也没有建立一个封闭的标准组织。相反，他将 HTTP、HTML、URL 的规范完全开放，任何人都可以免费使用、修改、扩展。

这在当时是非常罕见的。1990年代，很多公司都在试图建立自己的"信息高速公路"，但它们大多是封闭的、收费的、需要专门客户端的系统。

Web 的开放性，让它在竞争中脱颖而出。**开放，意味着没有单点控制，没有寻租，没有准入门槛**。任何人都可以建立网站，任何人都可以访问网站，没有中间商赚差价。

### 3. 无需许可(Permissionless)

这是 Web 最强大的特性之一：**你不需要任何人的批准，就可以创建一个网站，发布你的内容，链接到其他网站**。

没有审核，没有准入，没有"先交钱再上线"。你只需要一台服务器、一个域名，就可以加入这个全球网络。

这种"无需许可"的特性，释放了巨大的创新能量。从个人博客到维基百科，从 GitHub 到 YouTube，无数伟大的创新都是从一个不需要任何人批准的网站开始的。

**无需许可，意味着创新的速度不再受限于审批流程，而只受限于创造者的想象力。**

### 4. 基于现有基础设施(Built on Existing Infrastructure)

HTTP 没有试图重新发明轮子。它建立在 TCP/IP 之上，使用 DNS 进行域名解析，依赖现有的互联网基础设施。

这意味着，Web 从第一天起，就可以在全球范围内工作。你不需要等待新的网络协议被部署，不需要等待新的硬件被制造，不需要等待新的标准被批准。只要你能上网，你就能访问 Web。

**基于现有基础设施，大大降低了部署成本，加速了普及速度。**

### 本质判断：解放信息的生产与分发

Web 1.0 的核心成就，是**解放了信息的生产与分发能力**。

在此之前，发布信息需要出版社、印刷厂、发行渠道。Web 让任何人都可以成为信息的发布者。

但这个时代有一个关键特征：**人是主要的"解释者"和"执行者"**。

网页是给人看的，超链接是给人点的，信息是给人读的。整个 Web 的设计，都围绕着人类的认知能力和操作能力展开。

**生产力的主体，仍然是人。**

这一点，为后来的平台化转型埋下了伏笔。

## 三、Web 2.0：平台化不是背叛，而是效率选择

如果 Web 1.0 的关键词是"开放"和"连接"，那么 Web 2.0 的关键词就是"平台"和"用户生成内容"。

2000年代初，随着宽带普及和技术进步，互联网开始从"只读"走向"读写"。博客、论坛、社交网络兴起，用户不再只是被动的信息消费者，而是积极的内容创造者。

这本来是一件好事。但随之而来的，是一场深刻的权力转移。

### 平台为什么会出现？

很多人把平台的崛起归咎于商业贪婪或道德堕落，但这种解释过于简单。

平台的出现，源于三个实实在在的问题：

#### 1. 信息过载

Web 1.0 成功地解决了信息发布的问题，但也带来了新的问题：信息太多了。

当互联网上有数十亿个网页时，人类根本无法靠自己找到需要的信息。搜索引擎的出现，正是为了解决这个问题。

Google 的 PageRank 算法，本质上是用"连接"来衡量信息的价值——被更多高质量网页链接的网页，往往更有价值。

**这是"连接即权力"的第一次异化：连接不再是平等的，而是有权重的。**

#### 2. 关系管理成本急剧上升

Web 1.0 时代，你可能关注几十个博客，通过 RSS 订阅。但当你的联系人达到数百、数千人时，手动管理关系变得不可能。

社交网络的出现，正是为了解决这个问题。Facebook、Twitter、微信，都在帮你管理关系：谁是你的朋友，谁的内容你可能感兴趣，谁在线上。

**平台成为了关系的组织者和中介。**

#### 3. 交易撮合的复杂性

电子商务的兴起，带来了新的需求：买家如何找到卖家？如何确保交易安全？如何解决纠纷？

淘宝、亚马逊、eBay 的出现，正是为了解决这些问题。它们提供了搜索、支付、物流、评价、售后等一整套服务。

**平台成为了交易的撮合者和信任中介。**

### 平台化的内在逻辑

归根结底，平台的出现解决了三个核心问题：

1. **内容筛选**（搜索 / 推荐）
2. **关系组织**（社交图谱）
3. **交易撮合**（电商、广告）

这三个问题的共同特点是：**它们都是为人类的注意力和操作能力优化的结果**。

人类的注意力是有限的，操作能力也是有限的。当信息和关系的规模超过人类的处理能力时，就需要某种"中介"来帮助筛选、组织、撮合。

**平台，就是这个中介。**

这不是道德问题，而是效率问题。在"以人类为主要生产力"的时代，平台化是必然选择。

## 四、封闭与垄断的内在驱动力

平台的出现，本身不是问题。问题在于，平台为什么会走向封闭和垄断？

答案在于软件的经济学特性。

### 软件的边际成本趋近于零

传统制造业，生产一件产品需要原材料、人工、设备。生产100件产品的成本，大致是生产1件的100倍。

但软件不同。开发一个软件需要成本，但复制一份软件几乎不需要成本。服务100个用户和服务1亿个用户，成本差异远小于100万倍。

**这意味着，软件天然具有规模效应。**

### 规模越大，价值越高

对于平台型软件，规模效应更加明显：

- **更多用户** → 产生更多数据
- **更多数据** → 训练更好的算法
- **更好的算法** → 提供更优的体验
- **更优的体验** → 吸引更多用户

这形成了一个正反馈飞轮：

> **更多用户 → 更高效率 → 更强锁定 → 更大平台**

这就是为什么互联网行业容易出现"赢家通吃"的局面。

### 封闭是规模效应的必然结果

当一个平台占据主导地位后，它有充分的理由走向封闭：

1. **数据是核心资产**：开放数据意味着竞争对手可以免费获得你的核心资产
2. **用户锁定是护城河**：让用户难以离开，是维持垄断地位的关键
3. **生态控制是权力来源**：控制开发者生态，就能控制创新方向

微信可以决定哪些链接能被分享，哪些不能；淘宝可以决定哪些商品能被推荐，哪些不能；App Store 可以决定哪些应用能上架，哪些不能。

### 开放的高昂成本

相反，如果选择开放，则面临巨大的成本压力。

信息领域不是没有开放的业务。Email、通话、短信，这些都是典型的开放互联网应用。但它们有一个共同特点：**简单**。

Email 协议（SMTP/POP3/IMAP）诞生于 1970-1980 年代，核心功能只是"发送和接收文本消息"。通话和短信同样如此，功能单一，标准明确。

但当业务变得复杂时，开放的代价就会急剧上升：

- 不同厂商的实现需要相互兼容
- 协议升级需要所有参与方协调
- 偶然复杂度和必然复杂度叠加
- 调试和维护成本呈指数级增长

想象一下，如果微信的朋友圈、视频号、支付、小程序都要和其他平台开放互通，需要多少个标准？需要多少次协商？需要多少轮测试？这将是一个**超级大的软件工程灾难**。

**所以，随着互联网业务越来越复杂，开放度也越来越低。这不是道德选择，而是工程现实。**

### 一个关键判断

在传统软件时代，有一个基本逻辑：

> **开发一次软件，服务所有人；用户越多，效率越高；垄断不是偶然，而是内生结果。**

这不是说平台垄断是合理的，而是说，**如果底层技术不发生变化，互联网不可能自动回到开放**。

语义网和 Web3 的发展历程，恰恰证明了这一点。

## 五、为什么语义网没有打破封闭？

在 Web 2.0 走向封闭的同时，还有另一条路线在探索：语义网(Semantic Web)。

Tim Berners-Lee 在 1998 年提出了语义网的愿景：让机器能够理解网页的含义，而不仅仅是显示它们。通过给数据添加语义标注，机器可以自动推理、整合、分析信息，实现真正的"智能网络"。

听起来是不是很熟悉？这不就是今天 AI 智能体要做的事情吗？

这里推荐大家去读一下Tim博士在《科学美国人》上发表的关于语义网的文章，里面对智能体网络有一个具体的描述，和我们现在对智能体网络的设想非常类似。

但语义网没有大规模普及了。为什么？

归根结底，原因可以归纳为三点：**人工标注成本过高、缺乏商业驱动力、技术栈过于复杂**。

语义网要求网站开发者用 RDF、OWL 等语言给数据添加语义标注，但这对运营者来说没有直接收益，用户看不到，搜索引擎也不会给更高排名。更关键的是，当技术门槛过高、缺乏商业公司推动时，生态无法形成，网络效应无法启动。

语义网给我们留下了重要的启示：

> **让机器理解数据的语义，是一个正确的方向，但不能依赖人工标注，而应该依赖机器自动理解。**

这恰恰是大语言模型带来的革命性变化。

但在 AI 出现之前，语义网注定要失败——因为它试图用"制度或技术理想"，对抗当时的生产力现实。

## 六、为什么 Web3 没有打破封闭？

Web3 试图用区块链解决平台垄断：用户数据上链、应用由智能合约运行、数字资产通过 NFT 确权。愿景很美好，但同样没有成功。

问题在于三点：**把信任简化为上链问题**（现实信任还涉及执行、责任、纠纷）；**性能瓶颈难以逾越**（比特币每秒7笔 vs 支付宝每秒10万笔）；**用户体验太差**（助记词、私钥、Gas费让普通用户望而却步）。

Web3 的深层问题和语义网一样：**它试图用"制度或技术理想"，对抗当时的生产力现实。** 在"以人类为主要生产力"的时代，管理私钥、支付 Gas 费、等待区块确认，都是不可接受的成本。Web3 没有解决"谁来行动"的问题——人类仍然是主要的执行者，但人类的能力和意愿，不足以支撑去中心化的愿景。

## 结语：Web 的演进不是错误，而是每一代的最优解

回到文章开头的问题：**一个为"连接"而生的网络，为什么会不可避免地走向平台化与封闭？**

答案是：**因为在每一个时代，人们都在选择当时生产力条件下的最优解。**

- Web 1.0 解放了信息的生产，但带来了信息过载
- Web 2.0 组织了海量信息，但形成了平台垄断
- 语义网试图让机器理解数据，但依赖人工标注，成本过高
- Web3 试图用区块链去中心化，但忽视了用户体验和效率

**封闭不是阴谋，而是在"以人类为主要生产力"的时代，效率与规模经济的必然结果。**

这给我们一个重要的启示：

> **如果生产力不发生根本性变化，互联网不可能自动回到开放。**

那么，什么样的生产力变化，能够打破这个循环？

答案是：**当执行者从人类变成 AI 智能体时**。

AI 智能体不需要图形界面，不受注意力限制，不在乎管理私钥的复杂性，不害怕信息过载。它们可以直接通过协议通信，自主发现和连接服务，自动协商和执行任务。

**这就是 Agentic Web 的历史机遇。**
