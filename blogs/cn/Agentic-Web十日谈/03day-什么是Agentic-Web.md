# Agentic Web 十日谈·第三日：什么是 Agentic Web？当智能体成为互联网的第一公民

> 最近比较忙，上一篇和这一篇之间隔的时间有点长。不过会坚持写完。

> **核心问题**：到底什么是Agentic Web？

我现在还给不了一个非常严格、学术意义上的定义，但是我们可以看到Agentic Web的三个特征，特别是区别于传统互联网的地方。

在前两篇，我们回顾了 Web 封闭化的历史，推导出智能体作为新的执行主体，需要一个开放的互联网环境来获取上下文和服务，才能够更大限度的是否AI的能力。

今天，我们主要讨论的是，如果互联网的主要用户不再是「人」，而是「智能体」，这个网络会变成什么样子？

很多人也许会说：「你说的 Agentic Web，不就是现在的互联网加上 API 吗？」

**Agentic Web 不是给现有互联网打个补丁。** 就像移动互联网不只是「PC 互联网 + 手机」——它带来了位置服务、永远在线、触控交互等全新范式。

Agentic Web 也一样，它带来三个根本性的变化。

---

## 一、初步定义 Agentic Web

先给个初步定义：

> **Agentic Web 是一个以智能体为主体、以标准协议为核心、以开放协作为基本形态的新一代互联网。**

三个关键词：

1.  **主体变了**：从「人」变成「智能体」。
2.  **连接方式变了**：从「UI」变成「协议」。
3.  **协作形态变了**：从「数据孤岛」变成「开放连接」。

下面一个个说下我的理解。

## 三、转变二：从 UI 驱动走向协议驱动

用户从「人」变成了「智能体」，连接方式也得跟着变。

今天你想让智能体帮你订餐，现有方案（Computer Use、Browser Use）还在模拟人类操作：
1.  打开浏览器
2.  输入网址
3.  等页面加载（包括广告）
4.  识别哪个是「预订」按钮
5.  模拟鼠标点击

**这套方案又慢又脆弱。** 网页改版、按钮挪位置、弹个广告，任何 UI 变化都可能让任务失败。

**在 Agentic Web 中，协议取代 UI 成为核心。**

服务提供商不再只提供 HTML 网页，而是提供标准的**智能体描述协议（Agent Description Protocol）**。
-   不用告诉智能体「这是一个红色按钮，上面写着预订」，
-   直接通过协议告诉它：`Function: book_table(time, pax, requirements)`。

UI 是给人看的，需要视觉反馈和情绪引导；
协议是给机器用的，需要结构化数据和确定性逻辑。

**未来的互联网会分成两层：**
1.  **表层（Human Layer）**：保留精美 UI，供人类娱乐、社交、体验。
2.  **里层（Agent Layer）**：基于标准协议的能力网络，供智能体交换数据、执行任务。

**Agentic Web，就是这个正在形成的「里层」。**

## 四、转变三：从平台封闭走向开放协作

这个转变最难。

今天的互联网是「平台化」的。超级 App 希望把所有服务都圈在自己的围墙里——你想打车？用我的。想点外卖？用我的。想看电影？还在我的 App 里。

这种模式对人类来说虽然臃肿，但勉强能用；对智能体来说就明显受限了。

**智能体天生需要「组合」能力。**

想象一个场景：**「帮我策划一次去日本的旅行。」**

在封闭网络中，没有一个 App 能独立完成这个任务：
-   旅游 App 能订票，但不知道你的日程（在日历 App 里）。
-   日历 App 知道时间，但无法支付（在银行 App 里）。
-   银行 App 能支付，但不懂你的攻略偏好（在社交 App 里）。

在 Agentic Web 中，连接形态是**开放协作**：

用户的「个人助手智能体」不需要自己拥有所有能力，它可以动态发现并连接其他专精智能体：
1.  连接**酒店智能体**预订酒店。
2.  连接**景点智能体**预订景点门票。
3.  连接**航空公司智能体**预订机票。
4.  最后调用**支付智能体**完成结算。

这些智能体可能属于不同公司，甚至是个体开发者，但它们通过通用的**智能体通信协议（Agent Communication Protocol）**协作。

**不再是一个个孤岛，而是可以自由拼装的能力网络。**

> **【插图概念提示】**
>
> **画面描述**：
> 左侧：几个巨大的封闭堡垒（代表巨头平台），堡垒之间有深沟高墙，互不相通。
> 右侧：无数个大小不一的节点（代表各种 Agent），它们之间通过发光的线条（协议）自由连接，形成一张大型网状结构。某个任务触发时，一条路径迅速点亮多个节点。
> **核心隐喻**：从「帝国割据」到「协作网络」。

## 五、这不只是技术升级

理解了上面三个转变，你就会明白为什么我们说 Agentic Web 是「连接目标的回归」。

Tim Berners-Lee 创造万维网的初衷，就是为了「连接」。
-   Web 1.0 连接了文档。
-   Web 2.0 连接了人。
-   **Agentic Web 将连接服务和行动。**

当智能体能够跨越平台围墙，在网络中顺畅流动；
当服务能力像电力一样，通过标准插座（协议）即插即用；
当每一个小开发者，都能通过协议被全球智能体发现并调用。

我们看到的，不只是效率提升。

## 结语：巨头会答应吗？

「听起来挺美好，但巨头们会答应吗？」

这是很多人听到 Agentic Web 构想时的第一反应。

确实，现有互联网巨头靠封闭生态赚了大钱。让他们开放接口、打破围墙，难度可想而知。

**但冲突已经开始了。**

2024 年末到 2025 年初，我们目睹了智能体生产力与旧生产关系的第一次剧烈碰撞：豆包手机助手被封杀事件。

这不只是商业纠纷，这是一个信号：**当新的执行主体试图在旧的生产关系中穿行时，必然会擦出火花。**
