## 第 2 日

### **为什么 AI 需要一个开放的互联网？Agentic Web 的第一性原理**

（对应：为什么 AI 需要开放的互联网）

**核心判断（一句话）**

> 互联网之所以封闭，是因为它服务的是人；AI 必须开放，是因为它需要行动。

**结构大纲**

* AI / Agent 的本质能力：理解 → 决策 → 执行
* 封闭平台如何切断上下文、能力与执行路径
* 开放不是价值立场，而是第一性原理
* Agentic Web 的三个“不可妥协条件”：

  * 上下文可流动
  * 能力可发现
  * 行动可组合

## 第 3 日

### **什么是 Agentic Web？当智能体成为互联网的第一公民**

（对应：什么是 Agentic Web，有什么特征）

**核心问题**

> 如果不是“人点网页”，而是“智能体办事”，互联网会变成什么？

**结构大纲**

* Agentic Web 的一句话定义：以智能体为主体、以协议为核心、以开放协作为基本形态的新一代互联网
* 三个关键转变（对应图片三点）：

  * 从“人访问网页”到“智能体代表人行动、协作与决策”
  * 从 UI 驱动走向协议驱动（标准协议、接口与能力调用成为核心）
  * 从平台封闭走向开放协作（跨平台发现、连接与协作）


---


## 第 4 日

### **第一次正面碰撞：豆包手机助手与旧互联网生产关系**

（对应：豆包被封事件）

**核心判断（一句话）**

> 豆包不是一个产品事件，而是先进生产力第一次正面撞上旧互联网生产关系。

**结构大纲**

* 豆包手机助手代表的生产力：为什么，因为豆包手机助手可以操作一切，连接一切，虽然使用的方式是computer use的方式，但是是第一个让人看到个人助手形态的产品。
* 为什么“跨应用操作”会触发集体封锁：根本的原因在于商业模式的冲突。任何APP都不愿意给别人做嫁衣。
* 平台封杀的结构性原因：平台足够强大，短期并没有动力把服务能力“分出去”，那相当于与割了他们的命脉。
* 这是新的生产力与生产关系的第一次碰撞，未来还会有更多。

千问打通了阿里内部的生态，但是其本质上，仍然是一个封闭的产品。

## 写作指南

### 内容结构建议
每篇文章采用以下结构:
1. **引言**(10%): 引出话题,激发兴趣
2. **核心观点**(5%): 一句话总结 + 3-5 个要点
3. **主体内容**(75%): 按主题展开,穿插案例
4. **总结与展望**(10%): 呼应主题,引向下一篇

### 风格要求
- **平衡深度与广度**: 技术、商业、趋势三维度兼顾
- **中立客观**: ANP 作为案例之一,不过度推广
- **案例丰富**: 引用具体公司、产品、协议作为例证
- **可读性强**: 避免过度技术化,使用类比和图表
- **引发思考**: 提出开放性问题,鼓励读者深入思考

### 参考素材
- 技术白皮书: 架构、原理、设计哲学
- 现有博客: 观点、案例、数据
- 协议文档: MCP、A2A、ACP、ANP 的对比
- 行业新闻: OpenAI、Google、Anthropic 的最新动态
- 学术论文: W3C 标准、DID 规范等
