# ANP 是什么?

ANP（Agent Network Protocol，智能体网络协议）是面向智能体互联的开放通信协议，旨在成为智能体互联网时代的基础设施。

## 核心价值主张

### 1. AI 原生设计

ANP 专为智能体之间的直接通信设计，而非传统的人机交互：

- **自然语言接口**：支持智能体之间的自然语言通信
- **结构化接口**：兼容 OpenRPC、JSON-RPC 等标准协议
- **能力自描述**：通过智能体描述协议 (ADP) 实现能力发现

### 2. 去中心化身份

基于 W3C DID 标准的 `did:wba` 方法：

- **自主身份**：智能体拥有自主控制的数字身份
- **无需中心化**：不依赖中心化认证机构
- **端到端认证**：基于公钥密码学的安全认证

### 3. 安全第一

采用零信任架构，确保所有通信安全：

- **必须认证**：所有敏感接口必须经过身份认证
- **加密传输**：所有关键数据通过 HTTPS 加密
- **重放防护**：基于 nonce 和时间戳的重放攻击防护

### 4. 协议兼容与复用

充分复用成熟的互联网标准：

- **Web 基础设施**：基于 HTTPS、`.well-known`、Webhook
- **标准协议**：OpenRPC、JSON-RPC、JSON-LD、JWS
- **模块化设计**：核心组件可独立使用或自由组合

## ANP 三层架构

![ANP 三层架构](/images/anp-architecture.png)

### 1. 身份与加密通信层

- 基于 `did:wba` 的去中心化身份认证
- 端到端加密通信
- 请求签名与验证

### 2. 元协议层

- 智能体之间协商通信协议的协议
- 支持自组织和自协商
- 协议动态选择与适配

### 3. 应用协议层

- **智能体描述协议 (ADP)**：描述智能体的能力和接口
- **智能体发现协议**：通过 `.well-known` 发现智能体
- **智能体支付协议 (AP2)**：支持智能体之间的支付交易

## 为什么选择 ANP?

### 与传统 API 对比

| 特性 | 传统 API | ANP |
| --- | --- | --- |
| 设计目标 | 人机交互 | 智能体间通信 |
| 身份认证 | OAuth/API Key | 去中心化 DID |
| 能力发现 | 手动查阅文档 | 自描述 + 自发现 |
| 接口类型 | 仅结构化接口 | 结构化 + 自然语言 |
| 安全模型 | 信任边界 | 零信任架构 |

### 适用场景

- **智能体互联**：多个智能体之间的协作与通信
- **服务发现**：自动发现并连接到其他智能体服务
- **安全交易**：智能体之间的支付和交易
- **联邦学习**：分布式智能体协作学习
